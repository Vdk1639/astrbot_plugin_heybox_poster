## 文档联合评审

主代理核对草案覆盖、公共契约和源码证据；Lorentz 专项复核第一单的并发、重试、额度及审核恢复；Poincare 专项复核第二单的聚合兼容、身份、评分幂等及误判。两位子代理直接修订各自文档，写入范围互不重叠。

| 发现 | 正式规格的处置 | 源码依据 |
|---|---|---|
| 生成成本与实际评论混算，失败退额会被滥用 | 分开通知处理预算与真实发送额度；处理预算不返还 | `runtime.py::deliver`、`repository.py::reserve_proactive_request` |
| 只查 sent 无法挡住并发生成和待审重复 | 持久楼层占位、原子准入、独占执行权 | `notification_service.py::_handle` |
| 重试号与生成次数不一致 | 区分 defer、恢复与真正重新生成 | `repository.py::schedule_retry/defer_event` |
| 一条审核可有多个来源 | 全来源复查与结算；实际发送只计一次 | `core/review.py::submit`、`review_events` |
| 本地拒绝会被误报未知 | 统一 pending/policy_blocked/reason，页面保留审批能力 | `core/publishing.py::approve`、`pages/account/publishing.js` |
| 审核库与业务库不能假设原子同步 | 稳定关联键、幂等结算与启动核对 | `core/review.py`、`xiaoheihe/database.py` |
| 聚合昵称、空 UID 和跨档案合并易误认身份 | 最新昵称、匿名事件独立组、档案隔离 | `repository.py::list_events`、`models.py::Notification` |
| 重试或零命中会重复评分，积压会误判洪泛 | 事件完成标记、事务内窗口去重、区分回填资格 | `notification_service.py::_handle`、`parsers.py` |
| 宽泛关键词误伤正常交流 | 少量固定规则、默认观察、人工处置独立 | `context_builder.py`、`security.py` |
| 正文清理与整行删除语义不同 | 正文清理仍可用 UID；关联丢失须保守停止审批 | `repository.py::prune_event_bodies` |

两份正式单已统一账号、档案、来源、UTC 日界、审核本地拒绝和发送未知的含义；待实现功能清单保持未勾选。文档评审通过不代表功能测试通过。

### 交叉复核及修复

后端、API、页面分别实施，另行对共享后端与发送链路只读复核。发现并修复以下问题，每项均补充回归：

1. 客户端限速等待后的最终检查：将检查移到实际 HTTP 请求之前，等待期间切换模拟或取消时保持零请求并正确释放本次发送额度；跨日重新登记实际请求日期。
2. 主动事件生成期间换号：在构建上下文前持久绑定原 UID，后续分发不能重新绑定。
3. 终态完成时间与过期楼层恢复：全部来源写入完成时间，恢复尊重去重保留期，旧审核历史不能重建过期占位。
4. 人工处置事务中的快照读取：读取与写事务串行，未提交且最终回滚的解除操作不能暂时放行。
5. 积压事件的窗口依赖清理：待评估事件所需的历史资格/hash/窗口记录保留到评估完成。
6. 评分等待事务锁后的时间：取得锁后取时，避免旧时间造成冷却提前结束。
7. Unicode 空白 UID：新入库与历史查询统一空白语义，匿名事件不合并成已验证用户。
8. 最后异步复查期间跨 UTC 日：在全部异步检查完成后同步核对登记日；跨日则不发 HTTP，释放本次额度和冷却，回到待审。补充次日额度已被其他操作占满时的真实 MockTransport 零请求测试。

后端独立复验对第 4—7 项执行了 5 组复现断言，并通过风险/API 专项 239 项。全部修复已纳入下列最终全量回归。

发送链路独立复核确认第 1—3 项通过；第 8 项复现也已通过：跨日零 HTTP、回到 pending、释放本次预占和冷却；当日额度满时重审仍受限，下一日批准只发送一次并计入当日额度。复核未留下可复现阻断。

### 最终回归结果

在 Python 3.12 与 Node.js 下顺序执行；网络响应全部为模拟，数据库为临时库。

| 命令 | 结果 |
|---|---|
| `.venv/Scripts/python.exe -m unittest discover -s tests -q` | 173 项通过，20.327 秒 |
| `.venv/Scripts/python.exe -m pytest adapter_tests -q --asyncio-mode=auto --basetemp=.test-runs/final-adapter-crossday --ignore-glob=heybox-test-*` | 699 项通过，11.22 秒 |
| `node tests/test_dashboard.mjs` | 35 项通过 |
| `git diff --check` | 通过 |

本机设置 `PYTHONUTF8=1`，并以 `PYTHONTZPATH` 指向现有 bundled tzdata；无需新增依赖。Windows 沙箱临时目录 ACL 会导致测试建库误报，因此完整 Python 回归在已批准的本地执行环境运行。测试日志位于 `.test-runs/final-unittest.log` 与 `.test-runs/final-adapter.log`，只作本机证据，不提交日志或临时数据。
